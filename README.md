# GRASS GIS Scripts — Computing Vegetation Indices from Landsat over the Niger River Delta

GRASS GIS scripts used in the peer-reviewed article by Polina Lemenkova and Olivier Debeir.

**Paper:** Computing Vegetation Indices from the Satellite Images Using GRASS GIS Scripts for Monitoring Mangrove Forests in the Coastal Landscapes of Niger Delta, Nigeria
**Published in:** *Journal of Marine Science and Engineering* **2023**, *11*(4), 871
**DOI:** https://doi.org/10.3390/jmse11040871

## Contents
Scripts based on the GRASS GIS `i.vi` and `i.landsat.toar` modules to preprocess Landsat 8-9 OLI/TIRS scenes (top-of-atmosphere reflectance, DOS1) and compute ten vegetation indices: ARVI, GARI, GVI, DVI, PVI, GEMI, NDWI, MSAVI2, IPVI and EVI. Includes k-means land-cover clustering and correlation analysis for four scenes (2013, 2015, 2021, 2022).
